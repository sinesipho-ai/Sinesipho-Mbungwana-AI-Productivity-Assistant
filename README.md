# AI-Powered Productivity Assistant
by Sinesipho Mbungwana - CAPACITI AI Accelerator

An AI assistant designed to automate workplace tasks.

## Project Overview
This project helps automate:
- Email generation
- Meeting summarization
- Task planning
- Research assistance
- Chatbot interaction

## Tools Used
- ChatGPT, Gemini, Notion AI
- Python + Streamlit
- Prompt Engineering

## Prompt Engineering Techniques Demonstrated
1. Role Prompting: "You are a professional workplace assistant..."
2. Few-Shot Learning: Providing examples of good emails
3. Chain-of-Thought: "Think step-by-step before summarizing"
4. Constrained Prompting: "Keep under 150 words, professional tone"

## How to Run
pip install streamlit
streamlit run streamlit_app.py

## Ethical and Responsible AI Use
- No personal data is stored
- All outputs require human review before sending
- Transparent that content is AI-generated
- Built for productivity, not replacement of human judgment
